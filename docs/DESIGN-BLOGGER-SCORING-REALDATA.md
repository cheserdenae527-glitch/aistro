# 博主真实数据评分系统 — 完整设计 v2

> 状态：设计稿，尚未改代码。
> 目标场景：用博主分析筛选优质达人、过滤低质账号。
> 核心原则：**评分只使用真实抓取到的详情数据；缺失就是缺失，绝不估算、不外推。**
> 权威实现跟踪：PLAN-CRAWLER.md C9 / SPEC-CRAWLER.md §11（均为 [规划中]）。

---

## 0. 设计目标

分数只回答一个问题：**这个博主值不值得合作**。
所有指标选择、权重分配、阈值设计都服务于这个目标，不是为了“全面描述博主”。

---

## 1. 真实样本定义（数据准入规则）

一篇笔记计入“真实样本”，必须同时满足：

- 详情接口抓取成功（非风控失败、非 `data:null`）
- 点赞、收藏、评论、分享四个字段均非空
- 有明确发布时间

未满足任一条件的笔记**不计入任何分数计算**，只计入覆盖率分母。

---

## 2. 分层归一化框架（核心改进）

### 2.1 为什么必须分层

同样是“互动率 5%”，对 5000 粉账号可能只是及格线，对 200 万粉账号可能已是行业顶尖。
粉丝基数越大，互动率天然被稀释。全平台一套阈值会系统性低估大账号、高估小账号。

### 2.2 粉丝分层

| 层级 | 粉丝范围 |
|---|---|
| T1 尾部 | 1,000 - 10,000 |
| T2 腰部 | 10,000 - 100,000 |
| T3 头部 | 100,000 - 1,000,000 |
| T4 顶部 | ≥1,000,000 |

互动质量维度的映射阈值按层级分别标定，不共用一套数字（见 §4.1）。

### 2.3 内容类型归一化

图文与视频互动结构天然不同（视频更易获赞、图文更易收藏），混发账号直接比较原始值会失真：

```
类型内标准化互动 = 该笔记真实加权互动 / 该账号该类型笔记真实加权互动中位数 × 100
```

“内容稳定产出力”（§4.2）用标准化互动判定“优质笔记”，避免混发类型被误判波动大。

**边界处理：**
- 某类型真实样本 < 3 篇时，中位数不可靠，改用“账号全类型真实样本中位数”做分母。
- 中位数为 0（该类型全部互动为 0）时，标准化互动记为 0，避免除零；后续闸门会处理刷量/倒挂。

---

## 3. 核心指标：真实加权互动

```
真实加权互动 = 点赞×1 + 收藏×4 + 评论×5 + 分享×6
```

权重逻辑：点赞成本最低、最容易刷，权重压到底；收藏代表“想要/想去”的行动意图；评论代表真实讨论；分享最难伪造、传播价值最高，权重最高。

---

## 4. 四个维度（权重合计 100%）

### 4.1 真实互动质量 — 35%

评分窗口：近 90 天真实样本（全量抓取下低频号 30 天可能零篇，90 天兼顾新鲜度与样本量）。

```
篇均互动率 = Σ(近90天真实样本加权互动) / 粉丝数 / 近90天真实样本篇数
```

- 用“篇均”而非“总量”，避免发得多的账号靠数量堆分。
- 粉丝数口径：使用当前粉丝数（简单可复现）；若后续有订阅快照，可升级为窗口内平均粉丝数，当前不强制。

按粉丝分层分别映射（**以下为初版占位，必须按 §8 标定后替换**）：

| 层级 | 100分 | 70分 | 40分 | 0分 |
|---|---|---|---|---|
| T1 尾部 | ≥6% | 3% | 1% | 0% |
| T2 腰部 | ≥4% | 2% | 0.8% | 0% |
| T3 头部 | ≥2.5% | 1.2% | 0.5% | 0% |
| T4 顶部 | ≥1.5% | 0.7% | 0.3% | 0% |

分段间线性插值。

### 4.2 内容稳定产出力 — 30%

用“稳定输出优质内容的能力”替代单纯“爆文率”：筛选要的是“大概率靠谱”，不是“偶尔运气好”。

```
优质笔记 = 类型内标准化互动 ≥ 200（即该类型中位数 × 2）
优质笔记占比 = 优质笔记数 / 真实样本总数

产出波动性 CV = 真实样本标准化互动的变异系数（标准差 / 均值）

稳定产出分 = 优质笔记占比得分 × 0.7 + (1 - min(CV, 1)) × 100 × 0.3
```

优质笔记占比映射（初版占位）：≥25%→100，15%→70，8%→40，0→0

**边界处理：** 标准化互动全部为 0 时 CV 无意义，稳定产出分直接取优质笔记占比得分（波动项置中性 50）。

### 4.3 持续经营度 — 20%

合并“活跃度”与“新鲜度”。

```
发布频率分（近90天周均发布数）：≥3→100，2→75，1→50，0.5→30，<0.5→0
新鲜度分（最新真实笔记发布距今天数）：≤7天→100，≤30天→70，≤60天→40，>60天→0

持续经营度 = 发布频率分 × 0.6 + 新鲜度分 × 0.4
```

`>60天` 同时触发 §5 发布停滞闸门：维度分会降，等级还会额外降档。

### 4.4 趋势 — 15%（主动降权）

真实数据、不做估算平滑后，短窗口趋势噪声更大，小账号样本少时尤其明显，权重不宜过高。

```
按真实样本数量对半分（按篇数，不按天数）
比值 = 近半程平均标准化互动 / 前半程平均标准化互动

趋势分：≥200%→100，150%→85，100%→60，70%→40，≤50%→15（分段间线性插值）
```

**边界处理：**
- 真实样本 < 10 篇：趋势维度不计分，权重按比例重新归一化（35/30/20 → 约 41%/35%/24%），并在 insights 注明“样本不足以计算趋势”。
- 前半程为空或平均标准化互动为 0，而后半程有值：趋势分给 60（中性，按“从无到有”保守处理），注明口径。
- 后半程为空：视为活跃度/停滞信号，趋势分给 30 并触发“近期可能停更”提示。

## 5. 资格闸门（一票否决，独立于加权分数）

闸门回答“这个账号能不能信”，加权分数回答“这个人有多优秀”：
**闸门优先于分数**，按以下优先级顺序应用，命中靠前的闸门不再判断后面的。

| 优先级 | 闸门 | 判定 | 处理方式 |
|---|---|---|---|
| 1 | 数据覆盖率不达标 | 见 §6 | 直接返回“数据不足，暂不评分”，不再判断其他闸门 |
| 2 | 刷量嫌疑 | 单篇：(评论+收藏+分享)/点赞 <0.5% 且 点赞≥真实样本点赞中位数×3；命中笔记占真实样本 >20% | 强制结论“疑似刷量，不建议合作”，覆盖加权分数 |
| 3 | 粉丝互动倒挂 | §4.1 的篇均互动率低于该层级最低健康线（初版：T1<1%，T2<0.6%，T3<0.3%，T4<0.15%，待标定） | 等级封顶“待观察” |
| 4 | 发布停滞 | 最新真实笔记发布距今 >60 天 | 等级降一档（待观察不再降） |
| 5 | 粉丝增长异常 | 仅已订阅博主（需 ≥2 次历史快照）；相邻两次快照增幅 >20% | 不改等级，仅 insights 标注“检测到粉丝数异常增长，建议人工核实” |

**边界处理：**
- 刷量判定中“真实样本点赞中位数”为 0 时，跳过单篇刷量判定（无法建立基准），改为在 insights 提示“样本互动过低，疑似异常”。
- 闸门 2/3 都命中的刷量账号：以闸门 2 的强制结论为准。

---

## 6. 数据可信度（已验证样本覆盖率）

术语调整：使用“已验证样本覆盖率”，避免和 “real” 混用产生歧义。

```
已验证样本覆盖率 = 已成功抓取详情的笔记数 / 账号笔记总数
```

| 覆盖率 | 可信度 | 结论 |
|---|---|---|
| ≥80% 且 ≥30 篇 | 高 | 正常评级 |
| ≥50% 且 ≥15 篇 | 中 | 评级，标注“样本有限” |
| 低于以上 | 低 | 不评级，“数据不足，暂不评分” |

---

## 7. 综合评分与等级合成

```
综合分 = 互动质量×35% + 内容稳定产出力×30% + 持续经营度×20% + 趋势×15%
（趋势跳过时按 §4.4 重新归一化）

初始等级：≥85卓越，70-84优秀，55-69良好，40-54一般，<40待观察

按 §5 优先级依次应用闸门，得到最终结论
```

---

## 8. 阈值标定方法论（占位数字如何变成真实数字）

1. 抽样标定集：每个粉丝分层至少 30-50 个账号，覆盖图文/视频混合类型，全量真实抓取。
2. 计算标定集的篇均互动率、优质笔记占比等指标的百分位分布，用百分位数反推分档（如 P90→100 分，P50→及格线）。
3. 用不重叠的验证集账号交叉验证，检查打分结果与人工评估一致性。
4. 分层阈值定期复核（建议每季度一次），因为平台大盘互动率会随生态漂移。

**本节是独立工作项：上面所有具体百分比都只是“结构占位”，用来验证公式与分层逻辑，不是最终生产数字。**

---

## 9. 明确不纳入核心分数的信号（Phase 2 可选）

- 评论内容质量（水军/垃圾评论识别）：需额外调用评论接口，抓取成本翻倍；先不做核心指标，可作为 insights 定性提示。
- 笔记类型结构占比：图文/视频比例仅做展示，不参与打分。
