# 直播工坊 · 值守人开播 SOP（操作手册）

> 版本：v1.0 · 2026-08-05（L3 真实 GPU 验证后定稿）
> 面向：运营 / 直播值守人（非部署工程师）
> 配套：`deploy/livestream/README.md`（部署）· `docs/contracts/livestream-api.md`（接口）
> 一句话：**AiRestro 只生成草稿与配置，不直接推流；开播前必须真人确认（值守 + AI 标识），推流由本地数字人引擎执行。**

---

## 0. 开播前 · 三件套自检（每次必查，缺一不可）

- [ ] **AI 标识**：直播间画面/简介展示 AI 标识文案（如「本直播间由 AI 数字人出镜，真人运营团队值守」）
- [ ] **LiveTalking 水印**：发布到 B站 / 视频号 / 抖音的视频带 LiveTalking 水印与标识（引擎开源声明要求）
- [ ] **真人值守**：有真人值班盯场（弹幕引导、危机处理、手动兜底），不是无人值守

> 平台对数字人直播的规则随时更新，以平台最新公告为准；本 SOP 不宣传、不出现「无人直播」类表述。

---

## 1. AiRestro 侧 · 准备开播包

### 1.1 确认项目已定稿
1. 打开 直播工坊 → 进入直播项目
2. 直播脚本 Tab：脚本状态必须是 **定稿**（`定稿` 按钮可点，`合规自检` 全通过）
3. 弹幕互动 Tab：确认回复规则 / 敏感词 / 转人工话题 已生成并检查

### 1.2 导出开播包
1. 直播脚本 Tab → 点 **导出开播包**
2. 在弹出的开播包窗口里检查：
   - 合规清单：全部通过（若有红色警示项，先回 Tab 修正再导出）
   - `engine_guide`：包含启动命令 + RTMP 地址 + 水印/AI 标识提醒
3. 点 **下载引擎文件**，得到 5 个文件：
   - `persona.json`（人设，含四必填字段 name/personality/style/knowledge_scope）
   - `wordlist.txt`（双向敏感词，每行一词，`regex:` 开头为正则）
   - `script.md`（直播脚本全文，值守人对照执行）
   - `reply_rules.json`（弹幕回复候选话术）
   - `engine_guide.txt`（引擎启动说明）
4. 也可点 **下载开播包** 存一份完整 JSON 归档

## 2. 引擎侧 · 检查本地引擎在线

### 2.1 启动引擎（部署工程师完成，见 README）
- LiveTalking / digital-human-livestream 已按 README 启动，端口 **8010**
- 引擎机器要求：wav2lip ≥ RTX 3060；musetalk ≥ RTX 3080Ti；`inferfps/finalfps ≥ 25` 才算实时

### 2.2 AiRestro「连接测试」（推荐，一键完成）
1. 直播项目 → 基本信息 Tab → 本地引擎连接配置
2. 填引擎管理后台地址（如 `http://<引擎IP>:8010`）
3. 点 **连接测试**，看到三项全绿：
   - `健康检查：通过（HTTP 200）`
   - `人设推送：已推送`
   - `敏感词推送：已推送`
4. 出现「最近健康检查」时间即成功

### 2.3 手动导入（引擎无管理后台 / 需要复核时）
- 管理后台 `http://<引擎IP>:8010/admin.html`：
  - persona：把 `persona.json` 内容粘贴保存
  - wordlist：把 `wordlist.txt` 内容粘贴保存（**注意：接口接收的是 `{"content": "文本"}`，不是数组**）
- 或把两个文件放到引擎 `config/` 目录（persona.json / wordlist.txt），重启引擎生效

## 3. 推流配置（选一条链路）

| 平台 | 推荐链路 | 说明 |
|---|---|---|
| **B站 / YouTube** | 引擎 RTMP 直推 | 用平台开播设置里的 RTMP 地址 + 串流密钥 |
| **抖音** | 引擎 → OBS → 抖音直播伴侣 | OBS 采集引擎虚拟摄像头，直播伴侣选「摄像头」源 |
| **视频号** | 引擎 → OBS → 视频号助手 | 同上，选 OBS 虚拟摄像头 |
| **小红书** | 引擎 → OBS → 小红书直播伴侣 | 同上 |

- 本机调试：浏览器打开 `http://localhost:8010/index.html`，点「开始连接」直接看画面
- 验证画面：数字人应随输入文本开口，无卡顿、无音画错位

## 4. 开播流程（真人值守）

### 4.1 场次排期与开播
1. 场次与复盘 Tab → 新建场次（选脚本/时间/值守人）
2. 状态 planned → live：弹出前置确认框
   - [ ] 已选值守人（operator）
   - [ ] 已确认 AI 标识文案
   - 全部勾选才能开播；**无脚本场次也必须有值守 + AI 标识**（纯人工直播场景）

### 4.2 开播中
- 用 `script.md` 按段落驱动数字人：把段落文本粘贴到引擎页面文本框发送（或值守人按脚本口播引导）
- 弹幕互动：从 `reply_rules.json` 选候选话术人工粘贴回复；命中转人工话题 → 真人接管
- 每 10~15 分钟：
  - [ ] 数字人画面正常（帧率实时、口型同步）
  - [ ] 直播间无违规弹幕（wordlist 已过滤，人工再扫一遍）
  - [ ] 优惠商品信息与脚本一致

### 4.3 结束
1. 场次状态 live → ended
2. 提示：平台直播数据需人工核对后录入复盘

---

## 5. 复盘（每次开播后必做）

1. 场次与复盘 Tab → 选中场次 → 录入复盘数据：
   - 观看人数 / 峰值 / 平均观看时长
   - 互动数 / 弹幕数 / 转粉
   - 订单数 / GMV / 核销数
   - 备注（问题、亮点）
2. 点 **AI 复盘** → 生成复盘报告，归档到场次
3. 复盘结论沉淀到下一场：改脚本 / 改弹幕规则 / 改优惠组合

## 6. 常见故障对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 连接测试失败「无法连接」 | 引擎没启动 / IP/端口错 / 防火墙 | 确认引擎进程与端口；`telnet <IP> 8010` |
| 连接测试失败「健康检查未通过」 | 引擎版本无 /health（纯 LiveTalking） | 纯 LiveTalking 无管理后台 → 推送标记跳过属正常；改用 digital-human-livestream 或用 §2.3 手动导入 |
| 人设推送失败「缺少必需字段」 | persona 缺 name/personality/style/knowledge_scope | 重新导出开播包（AiRestro 已自动补齐）；手动粘贴时补全四字段 |
| 敏感词推送失败 | wordlist 用了数组格式 | 用 `{"content": "每行一词"}` 格式（§2.3） |
| 画面卡顿 / 音画不同步 | 帧率不足 | 看引擎日志 inferfps/finalfps ≥25；降分辨率 / 换 wav2lip / 升显卡 |
| WebRTC 连不上 | UDP 端口未放通 / AutoDL | 放通 TCP:8010 + UDP 全段；AutoDL 需自建 SRS/TURN |
| 弹幕不采集（B站） | 房间号错误 / 未开始直播 | 确认 room_id、`/admin/livestream/start`、平台直播已开 |

## 7. 合规红线（触犯即停播）

- [ ] 不宣传「无人直播 / 24小时无人直播」
- [ ] 不引导站外私下交易（微信转账等）
- [ ] 绝对化用语（最便宜/最好/第一/100%）不进话术
- [ ] 敏感词命中即拦截，转人工话题由真人接管
- [ ] 数字人直播规则变化 → 以平台最新公告为准
